Example Experiences¶

Example experiences can be found in the “mods” directory.

File

Description

modname.ts

This is the gameplay script for a mod.

modname.tscn

This is the Godot level with any spatial edits needed for the mod. This will need to be exported from Godot for use in an experience.

modname.strings.json

This is a predefined list of strings used in the mod.
