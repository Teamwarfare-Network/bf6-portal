Tips & Tricks¶

Optimizing Performance¶

  • Vehicle Count

    • Server performance can be affected when an experience has more than 40 vehicles active at one time, it is recommended to remain below this number.

  • Player Iteration

    • Where possible, store player states using your own variables that are set through events such as OnPlayerEnterCapturePoint and OnPlayerExitCapturePoint. This reduces the need to regularly iterate over all players, for example when updating your custom UI or running gameplay logic.

  • Managing UI Widgets

    • Where possible, maintain variables to track existing widgets instead of recreating them unnecessarily. Regular creation and deletion of widgets may impact performance.
