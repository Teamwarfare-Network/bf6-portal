## 1. Context

Today the aircraft ceiling is single-layer: at `aircraftCeiling`, `mod.SetMaxVehicleHeightLimitScale(scale)` caps engine vertical control authority. Pilots feel a hard wall with no warning. H-P1 inserts a **warning layer** between the user-tuned ceiling and the engine cap:

- **Cruising layer**: below the user-tuned `aircraftCeiling`. Normal flight.
- **Warning layer**: between `aircraftCeiling` and `aircraftCeiling + buffer`. A big centered HUD dialog appears for every occupant of the offending aircraft ("ALTITUDE WARNING / Descend immediately or you will be pushed down"). Static text. Auto-clears when the aircraft descends back below the soft threshold.
- **Hard layer**: at `aircraftCeiling + buffer` and above. The engine's `SetMaxVehicleHeightLimitScale` cap applies (raised to the hard altitude rather than the soft). Pilot can't climb past it.

The user-tuned **Aircraft Ceiling** knob in the Ready Dialog **keeps its existing label and HUD format** but its meaning changes from "hard ceiling" → "soft ceiling / warning threshold." The hard physical ceiling sits **buffer meters above** it. Default buffer = 25m; the buffer is **admin-tunable** via a new row in the Admin Panel, bounds [5, 200], step 5.

#### 3.5.b Repurpose the dead-code soft-enforcement loop into the warning-visibility loop

**Where**: existing function at [line 2499](../src/ready-dialog.ts#L2499).

**Replace** the function body. New shape:

```ts
// H-P1: 5Hz tick that iterates the aircraft-occupancy cache only (NOT mod.AllPlayers,
// NOT mod.AllVehicles). For each pid in playerInAircraftByPid, reads the player's vehicle
// position once; updates altitude-warning visibility with hysteresis. Also drives the
// per-second countdown decrement for any pid whose warning is currently visible.
const ALTITUDE_WARNING_COUNTDOWN_SECONDS = 3;

async function runAircraftWarningLoop(): Promise<void> {
    // Diff cache: last value written to each pid's countdown widget. Avoids repeating the same
    // text-write 5 times per second when the displayed digit hasn't changed.
    const lastCountdownByPid: Record<number, number> = {};

    while (true) {
        await mod.Wait(AIRCRAFT_SOFT_CEILING_TICK_SECONDS);
        if (!State.round.aircraftCeiling.customEnabled) continue;

        const softY = getAircraftSoftCeilingWorldY();
        if (softY <= 0) continue;
        const enterY = softY + AIRCRAFT_SOFT_CEILING_ENTER_BUFFER;
        const exitY = softY - AIRCRAFT_SOFT_CEILING_EXIT_BUFFER;
        const now = mod.GetMatchTimeElapsed();

        for (const pidStr in State.players.playerInAircraftByPid) {
            const pid = Number(pidStr);
            const player = safeFindPlayer(pid);
            if (!player || !mod.IsPlayerValid(player)) {
                delete State.players.playerInAircraftByPid[pid];
                setAltitudeWarningVisibleForPid(pid, false);
                delete lastCountdownByPid[pid];
                continue;
            }
            let vehicle: mod.Vehicle | undefined;
            try { vehicle = mod.GetVehicleFromPlayer(player); } catch (_e) {}
            if (!vehicle || !isAircraftVehicle(vehicle)) {
                // Cache desync (event drop) -- correct it.
                delete State.players.playerInAircraftByPid[pid];
                setAltitudeWarningVisibleForPid(pid, false);
                delete lastCountdownByPid[pid];
                continue;
            }
            const pos = mod.GetVehicleState(vehicle, mod.VehicleStateVector.VehiclePosition);
            const posY = mod.YComponentOf(pos);
            const currentlyVisible = !!State.players.altitudeWarningVisibleByPid?.[pid];
            if (!currentlyVisible && posY > enterY) {
                setAltitudeWarningVisibleForPid(pid, true);
            } else if (currentlyVisible && posY < exitY) {
                setAltitudeWarningVisibleForPid(pid, false);
                delete lastCountdownByPid[pid];
                continue;
            }

            // Countdown digit update: only runs while the warning is visible. Computes
            // remaining = COUNTDOWN_SECONDS - (now - startedAt), floored to 0 (terminal value).
            // No behavior at 0 -- the user explicitly deferred destruction. Widget text writes
            // are diff-gated against lastCountdownByPid so we write at most once per second.
            if (State.players.altitudeWarningVisibleByPid?.[pid]) {
                const startedAt = State.players.altitudeWarningStartedAtSecondsByPid[pid] ?? now;
                const elapsed = Math.max(0, now - startedAt);
                const remaining = Math.max(0, ALTITUDE_WARNING_COUNTDOWN_SECONDS - Math.floor(elapsed));
                if (lastCountdownByPid[pid] !== remaining) {
                    lastCountdownByPid[pid] = remaining;
                    const refs = State.hudCache.hudByPid[pid];
                    if (refs?.altitudeWarningCountdown) {
                        safeSetUITextLabel(
                            refs.altitudeWarningCountdown,
                            mod.Message(mod.stringkeys.twl.system.genericCounter, remaining)
                        );
                    }
                }
            }
        }
    }
}
```

Notes:
- `AIRCRAFT_CEILING_ENFORCEMENT_MODE !== "soft"` gate is removed (the constant is deleted).
- Token-cancellation pattern is dropped because the loop is no longer reactivatable on toggle. If `customEnabled` flips false, the inner condition skips work.
- The countdown is **per-pid** (each occupant has their own timer starting when their warning became visible). Reset semantics: descending below `exitY` clears both the visibility AND the `startedAtSecondsByPid` entry, so the next ascent starts a fresh 3-second window.
- The 5Hz tick reads `now` once per outer pass and reuses it across all pids — cheaper than per-pid `GetMatchTimeElapsed`.
- `lastCountdownByPid` lives in the loop's closure (not in `State`) because it's pure diff-gate noise that doesn't need to persist across module reload or admin reset.

#### 3.5.c New helper: `setAltitudeWarningVisibleForPid`

**Where**: new function alongside `runAircraftWarningLoop`.

```ts
// Per-pid widget visibility toggle. Tracks `altitudeWarningVisibleByPid` for diff gating
// so we don't write the same visibility every tick. Also manages the countdown lifecycle:
//   - On show:  stamp `startedAtSecondsByPid[pid] = now` and reset the countdown digit to 3.
//   - On hide:  delete the timestamp so the next ascent starts a fresh 3-second window.
function setAltitudeWarningVisibleForPid(pid: number, visible: boolean): void {
    const previously = !!State.players.altitudeWarningVisibleByPid?.[pid];
    if (previously === visible) return;
    State.players.altitudeWarningVisibleByPid[pid] = visible;
    const refs = State.hudCache.hudByPid[pid];
    if (!refs) return;
    safeSetUIWidgetVisible(refs.altitudeWarningTitle, visible);
    safeSetUIWidgetVisible(refs.altitudeWarningBody, visible);
    safeSetUIWidgetVisible(refs.altitudeWarningCountdown, visible);
    if (visible) {
        // Start (or restart) the countdown.
        State.players.altitudeWarningStartedAtSecondsByPid[pid] = mod.GetMatchTimeElapsed();
        // Seed the digit at 3 so the user sees a clean start before the next 5Hz tick repaints.
        if (refs.altitudeWarningCountdown) {
            safeSetUITextLabel(
                refs.altitudeWarningCountdown,
                mod.Message(mod.stringkeys.twl.system.genericCounter, ALTITUDE_WARNING_COUNTDOWN_SECONDS)
            );
        }
    } else {
        delete State.players.altitudeWarningStartedAtSecondsByPid[pid];
    }
}
```

## 6. Banned patterns guarded against

Per [AGENTS.md](../AGENTS.md):

- **ASCII-only source**: no em-dashes, smart quotes, arrows. New constant comments and inline strings stay ASCII. Postbuild step 11.5 hard-fails the build otherwise.
- **`mod.Message` string-key requirement**: all 5 new strings are registered in `strings.json` and accessed via `mod.stringkeys.*` (the `STR_*` consts in step 3.1).
- **No `mod.AddUIIcon`**: not used.
- **No `mod.ForcePlayerToSeat` + player teleport combination**: not used. `mod.GetVehicleFromPlayer` is wrapped in try/catch in the warning loop.
- **`try/catch` wraps engine reads** where stale handles are possible (`GetVehicleFromPlayer`, `GetVehicleState`).
- **Per-pid widget scope** ([memory `feedback_per_pid_ui_rule`](../AGENTS.md)): warning dialog widgets are per-pid (`Altitude_Warning_*_${pid}`); visibility writes go through `setAltitudeWarningVisibleForPid` which short-circuits when state hasn't changed.

## 9. Open follow-ups (not in scope for this plan)

- **Countdown-at-zero behavior**: The body text says "Descend immediately or you will be DESTROYED" but no actual destruction fires when the countdown hits 0. **User explicitly deferred deciding the at-zero action.** When the decision lands, the natural hook is inside `runAircraftWarningLoop` at the spot where `remaining === 0` — fire whatever consequence the user picks (kill, force-undeploy, vehicle DealDamage, etc.). The countdown widget already pins at 0; only the consequence-trigger is missing.
- **Sound effect on warning entry/exit**: The user's [Improvements Punchlist](../src/ImprovementsPunchlist.ts) mentions SFX for various events. An altitude-warning SFX (klaxon-style alarm) would pair naturally with this dialog, possibly retriggering at countdown 0. Conquest does this via `mod.PlaySound` driven by `primeBoundaryAlarmRuntime` ([conquest/src/boundary/enforcement.ts:62](../../conquest/src/boundary/enforcement.ts#L62)). Defer.
- **Per-map buffer override**: H-P4 (per-map mode defaults) could plumb `MapConfig.defaultAircraftHardBufferM?: number` when it lands. Currently the buffer is global + admin-tuned only.
- **Dynamic altitude readout in the dialog body**: locked at static text per Q4. If we later want "NNN m above safe altitude," that's a small follow-on — change the body to a format key + read posY each tick.
- **Confirm-on-buffer-change broadcast**: today's `aircraftCeilingChanged` Ready Dialog confirm fires a world-log line. The admin Buffer knob does NOT broadcast each click (would spam world log). If desired, add a debounced broadcast.
