# Conquest Bans

Class gadget and weapon ban list for all leagues (TWL).

**Legend**
- **Banned** - item is fully prohibited.
- **Supply Box** - item is not available from the loadout; players must obtain it from the in-world Supply Box (gadget locker).
- Parenthetical notes indicate scope qualifiers (e.g. `(Mines from bot)` = only the bot-deployed mines are banned).
